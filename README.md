# Магазин Макса — витрина (демо)

Фронтенд интернет-магазина: **Vue 3 + TypeScript + Vite + Tailwind CSS 4 + Pinia + Vue Router**.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

## Что реализовано

Главная, каталог с вложенными категориями, поиск, фильтры и сортировка, страница товара (варианты, количество),
корзина (сохраняется в localStorage), оформление заказа с валидацией, калькулятор доставки, страницы заказа,
«О магазине», «Доставка и оплата», «Контакты», 404.

## Стили и UI-кит

Индивидуальные стили лежат в объекте `classes` внутри `<script setup>` и применяются как `:class="classes.title"`.
Переиспользуемые компоненты — `src/components/ui` (Button, Input, Select, Badge, Alert, Skeleton, Breadcrumbs, Quantity, EmptyState).

## Ограничения (важно)

- **Все товары, цены и остатки — тестовые** (`src/data/mock.ts`). Каталог берётся через интерфейс `CatalogRepository`
  (`src/data/repository.ts`) — источник можно заменить на API без правок UI.
- **Доставка СДЭК/Ozon — mock** (`src/services/delivery.ts`), цифры условные и помечены «тест».
- **Оплата — имитация**: банковский модуль не подключён, заказы хранятся в браузере. Реальная оплата требует
  сервера, webhook-подтверждения и credentials провайдера.
- Не реализованы: бэкенд, админка, лиды, Яндекс Метрика, SEO/SSR, тесты, юридические тексты, ссылки на мессенджеры
  (заполняются в `src/config.ts`).

## Деплой

GitHub Pages через `.github/workflows/deploy.yml` (hash-роутинг, `BASE_PATH` задаётся автоматически).
