# Яндекс Метрика: подключение и цели

Счётчик подключается только в production-сборке и только если задан `VITE_YM_ID` (см. `.env.example`).
В dev/staging без ID события не отправляются. Персональные данные (имя, телефон, email, адрес) в Метрику не передаются.

| Цель (`reachGoal`) | Когда | Параметры |
|---|---|---|
| `view_item` | открыта карточка товара | `id` |
| `search` | отправлен поисковый запрос | `length` (длина запроса) |
| `view_category` | открыта категория | `id` |
| `add_to_cart` | товар добавлен в корзину | `id` (артикул) |
| `view_cart` | открыта непустая корзина | `items` |
| `begin_checkout` | открыто оформление | `items` |
| `select_delivery` | выбрана служба доставки | `provider` |
| `go_to_payment` | заказ создан, переход к оплате (карта) | `total` |
| `purchase` | оплата **подтверждена API** (не по возврату пользователя) | `total` |
| `lead_submit` | отправлена форма обратного звонка | — |

Электронная коммерция: `dataLayer` (`ecommerce: 'dataLayer'`): `detail`, `add`, `remove`, `purchase`.
SPA-переходы отправляются как `hit`.

## Отчёты в админке
Раздел «Аналитика» показывает данные заказов/заявок магазина. Отчёты Метрики требуют OAuth-токена API,
который должен храниться на сервере; пока он не подключён, админка показывает статус интеграции и **не имитирует отчёты**.
